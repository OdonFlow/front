Arquitetura Visual: Tríade de Cores e Alternância de Layouts

Este documento apresenta como o OdontoFlow estrutura sua identidade visual através da Tríade de Cores (Primária, Secundária e Terciária) baseada na regra 60-30-10, e formaliza o fluxo para permitir que a clínica e o usuário alternem dinamicamente entre o Layout Clínico Claro (Original) e o Layout Alto Contraste (Tríade Escuro).

Regra de Equilíbrio Proporção 60-30-10

60% fundos neutros, 30% estrutura secundária e 10% acentos primários/terciários.

Flexibilidade Multi-Tenant Padrão Clínica + Perfil

A clínica define o tema institucional e cada operador ajusta sua ergonomia pessoal.

Desempenho Técnico Zero Replicação de Código

Mesmos componentes React com alternância ágil de tokens CSS e variáveis Tailwind.

1. A Tríade de Cores no Software Odontológico (Regra 60-30-10)

Como as três cores atuam sinergicamente na interface sem sobrecarregar a visão de profissionais que passam 8 a 10 horas diante da tela.

#0D9488 • Teal 600 ~7% da tela

Cor Primária (Ação & Confirmação)

Exclusiva para os momentos decisivos onde o usuário precisa converter ou salvar:

  • Botões de CTA principais (+ Novo Agendamento, Salvar Prontuário)
  • Status de sucesso e atendimento concluído
  • Dentes com restauração concluída no Odontograma
#1E293B • Slate 800 ~30% da tela

Cor Secundária (Estrutura & Leitura)

Garante solidez visual, delimitando o software e guiando a leitura sem cansaço:

  • Barra lateral fixa de navegação (no modo Alto Contraste)
  • Títulos de cabeçalho, nomes de colunas e texto de alto contraste
  • Molduras estruturais e cartões executivos de KPI
#F59E0B • Âmbar 500 ~3% da tela

Cor Terciária (Farol de Alerta & Fila)

Ponto focal que se destaca imediatamente para situações que demandam atenção imediata:

  • Alertas médicos críticos (ex: Alergia a Penicilina no prontuário)
  • Pacientes aguardando na recepção além do tempo previsto
  • Procedimentos concluídos pendentes de baixa no caixa

2. Comparativo Visual dos Dois Layouts

Veja abaixo as duas abordagens visuais propostas para o OdontoFlow, seus pontos fortes e as recomendações práticas de uso.

Layout Clássico

1. Modo Clínico Claro

Utiliza fundo 100% claro e sidebar branca com divisória sutil. Transmite pureza, higiene e elegância minimalista.

Quando é mais indicado:
  • ✓ Ambientes de recepção amplamente iluminados por luz natural.
  • ✓ Clínicas que adotam identidade monocromática suave.
  • ✓ Impressão direta de relatórios e prontuários sem gasto excessivo de tinta.
Sidebar: Branca (#FFFFFF) • Fundo: Gelo (#F8FAFC) • Acento: Teal (#0D9488)
Layout Alto Contraste

2. Modo Tríade Escuro

Apresenta a barra lateral em Slate Escuro profundo (#1E293B), criando uma âncora visual física sólida à esquerda.

Quando é mais indicado:
  • ✓ Consultórios clínicos e salas cirúrgicas com luz focal e monitores de diagnóstico.
  • ✓ Redução acentuada da fadiga ocular em jornadas longas (8h+).
  • ✓ Máximo destaque para badges de alerta em âmbar (segurança clínica).
Sidebar: Slate Escuro (#1E293B) • Fundo: Gelo (#F8FAFC) • Tríade Ativa

4. Como Funciona o Fluxo de Escolha (Arquitetura de Preferências)

A recomendação ideal de produto combina controle institucional para a clínica com liberdade de conforto para cada profissional.

Nível 1 • Clínica (Tenant) Role: ADMIN

Configuração Global da Marca

O administrador da clínica acessa Configurações → Identidade Visual e estabelece:

  • Upload da Logomarca: Versão horizontal e ícone favicon.
  • Tríade de Cores Institucionais: Primária, Secundária e Terciária com verificação de contraste WCAG AA.
  • Tema Padrão da Clínica: Define se novos colaboradores iniciam com o layout Claro ou Alto Contraste.
Nível 2 • Usuário Individual Dentista & Recepção

Ergonomia & Conforto Pessoal

No topo de qualquer tela, ao lado da foto e CRO do usuário, existe um seletor rápido:

  • A recepcionista no balcão pode optar pelo tema Claro para acompanhar a luz natural do saguão.
  • O cirurgião-dentista na sala de procedimentos pode ativar o Alto Contraste para diminuir reflexos na tela sob iluminação cirúrgica.

Fluxo Passo a Passo da Aplicação

1
Login do Usuário

O sistema busca as variáveis da clínica (logo, paleta) e a preferência salva no perfil do operador.

2
Injeção Dinâmica

As cores primária, secundária e terciária são aplicadas como variáveis CSS na tag raiz (:root).

3
Alternância sem Reload

Ao clicar no alternador, a classe da sidebar alterna entre 'sidebar-light' e 'sidebar-dark' instantaneamente.

4
Persistência Automática

A preferência é salva no LocalStorage para carregamento rápido e sincronizada com a tabela de perfis.

5. Especificação Técnica para o Lovable (React + Tailwind + Supabase)

Como essa estrutura é codificada de forma limpa e manutenível sem duplicar componentes.

Tokens CSS Dinâmicos (:root)

:root {
  /* Injetadas via banco de dados da clínica */
  --color-primary: #0D9488;    /* Ações principais (Teal) */
  --color-secondary: #1E293B;  /* Estrutura e leitura (Slate) */
  --color-tertiary: #F59E0B;   /* Alertas e fila (Âmbar) */
}

/* Classe alternada no container raiz ou sidebar */
.layout-light-sidebar {
  --sidebar-bg: #FFFFFF;
  --sidebar-text: #475569;
  --sidebar-border: #E2E8F0;
}

.layout-dark-sidebar {
  --sidebar-bg: var(--color-secondary);
  --sidebar-text: #F8FAFC;
  --sidebar-border: #334155;
}

Esquema das Tabelas de Configuração

-- Configurações Institucionais da Clínica
ALTER TABLE clinics ADD COLUMN brand_settings JSONB DEFAULT '{
  "logo_url": null,
  "primary_color": "#0D9488",
  "secondary_color": "#1E293B",
  "tertiary_color": "#F59E0B",
  "default_layout": "dark_sidebar"
}'::jsonb;

-- Preferência Individual de Cada Usuário
ALTER TABLE profiles ADD COLUMN preferences JSONB DEFAULT '{
  "preferred_layout": "default", -- 'default', 'light', 'dark'
  "high_contrast_alerts": true
}'::jsonb;
